CPF é uma string pois não precisamos fazer operações com esse dado pois ele se trata de um identificador.

Construtores sempre levam a primeira letra maiscula e o nome da classe, eles sempre tem a primeira letra maiscula
e o nome da classe
ex:
class Mouse {

private:
//atributos -> caracteristicas 
    int sn;
    bool semFio;
    string marca;
    string modelo;
    int dpi;

public:

    // Construtor
    Mouse(int sn, bool semFio, string marca, string modelo, int dpi){
        this->sn = sn;
        this->semFio = semFio;
        this->marca = marca;
        this->modelo = modelo;
        this->dpi = dpi;     
    }

};
//Construtor vai ser o responsavel por crirar o objeto na memoria do computador


Os atributos mais importantes da classe tem que ser passado como parametros do Construtor.

Garbage Collector = Coletor de Lixo (Pesquisar)

Assinatura de uma função é o cabeçalho.
EX:
funcao(int parametro_1, int parametro_2)
