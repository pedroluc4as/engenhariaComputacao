1- a) COMPOSIÇÃO: É o tipo de associação em que você faz a manipulação dos atributos nela presente sem depender de atributos de outras classes. A composição é um tipo de associação independente.

AGREGAÇÃO: É um tipo de associação onde você precisar “chamar” objetos de outra classe para que você torne aquela classe “coerente” e funcional com o problema que você tem de implementar, a chamada de um atributo de outra classe é feita pelo uso de ponteiros. A agregação é um tipo de associação que depende de um atributo de outra classe.

b) Temos uma classe Aluno (CPF, nome, idade, endereço e RA), e esse aluno possui uma conta em uma instituição financeira (idBanco, idConta, valorReais), essa pessoa irá participar de um processo seletivo para o cadastro reserva de auxílio moradia do IFMS. O IFMS não tem acesso á conta bancaria do aluno e possui os seguintes atributos: nome, endereco, id, patrimonio e listaAuxilios.
	Teremos a classe aluno com os atributos string CPF, nome, idade, endereco, RA, a classe Instituicao_Financeira com os atributos string idBanco, idConta e int valorReais, a classe IFMS com string endereco, id; int patrimonio e um vetor listaAuxilios. Para o cadastro do aluno na lista reserva do auxilio o IFMS precisa ter acesso ao idBanco e idConta do aluno, porém esses dados estão encapsulados, para que o IFMS tenha acesso a esses dados ele precisa utilizar um ponteiro para a classe Instituicao_Financeira, que é a associação por agregação, onde IFMS necessita de Instituicao_Financeira para conseguir atingir seu objetivo de cadastrar o Aluno na listaAuxilios. Também como o IFMS necessita de Instituicao_Financeira, a Instituicao_Financeira necessita de quase todos os atributos de Aluno, assim também sendo associação por composição.
	Para o exemplo de composição podemos imaginar o seguinte cenário, alguém possui um carro(placa, cor, modelo), uma casa(numero, cor, bairro, cidade) e um celular(modelo, marca, cor). Uma pessoa necessita usar seu carro para ir até a sua casa buscar o carregador para seu celular que descarregou, percebe que nenhuma classe depende da outra, aqui temos a associação por composição, onde uma classe não depende da outra.
