# Criando uma Rede Neural do Zero

## 📋 Pré-requisitos
- Git instalado (https://git-scm.com/)
- Linux ou WSL (Windows Subsystem for Linux)
- Bash disponível no terminal

## 🚀 Passo a passo de instalação

1. Escolha um local no seu computador onde deseja salvar o projeto. Exemplo: dentro da pasta Documentos.
2. Crie uma pasta para os projetos (opcional):
   ```bash
   mkdir projetos && cd projetos
   ```
3. Clone o repositório:
   ```bash
   git clone https://codeberg.org/vsa/seeng-2025-nn.git
   ```
4. Entre na pasta do projeto:
   ```bash
   cd seeng-2025-nn
   ```
5. Execute o script de inicialização:
   ```bash
   bash init.sh
   ```

## ✅ Conclusão
Após seguir os passos acima, o ambiente estará configurado e pronto para uso no seu navegador.
